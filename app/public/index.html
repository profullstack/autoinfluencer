            How the connection works
            
    
              
  • Computer → us: the connector keeps an outbound HTTPS connection open. No ports to open, works behind any router.
    • 
              
  • Us → computer: jobs (post this, open this page, record this app) come back on that connection and run in the agent browser of the W3BS desktop layer.
    • 
              
  • You stay in charge: it asks once before an agent may drive, hands you every sign-in and CAPTCHA, and Super+Alt+Escape stops it at once.
    • 
            

            
Our own fleet runs this way: the server on dev2, the desktop on bonita, with a reverse SSH tunnel as a second path from dev2 to bonita.
